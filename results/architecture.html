Real-Time Multi-Camera Monitoring Dashboard

How video gets from four looping clips and any number of phones to one dashboard: three Docker containers on one Azure VM, with all analytics in Python.

One phone frame, start to finish

  1. Phone encodes its camera to H.264 and sends it with WebRTC (WHIP) to MediaMTX as phone-…-in.
  2. Dashboard pulls that stream over RTSP and decodes it into frames.
  3. Worker thread checks motion, brightness and blur on every frame. Once a second the YOLO thread counts people.
  4. Alerts that last 1.5 s are written to SQLite with a snapshot.
  5. ffmpeg encodes the frame with boxes drawn and pushes it back to MediaMTX over RTSP.
  6. Browser receives it with WebRTC (WHEP); numbers and alerts come from the JSON API.
